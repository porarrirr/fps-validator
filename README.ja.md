# FPS Validator

[English](README.md) | 日本語

Metalコンテンツを描画しながら、`CADisplayLink` のコールバック時刻からフレーム間隔とFPS推定値を記録するiOS向け検証アプリです。結果はCSVへ出力でき、条件をそろえた比較に利用できます。

## 測定しているもの

表示するFPSは `CADisplayLink` のコールバック頻度です。GPUコマンドの完了数や、ディスプレイへ物理的に提示されたフレーム数を直接数えるものではありません。

移動窓の推定式は次のとおりです。

$$FPS=\frac{n-1}{t_{last}-t_{first}}$$

CSVにはフレーム番号、時刻、目標FPS、移動窓FPS、フレーム時間、drop判定を保存します。

## 使い方

- 端末の最大リフレッシュレート以下の目標FPSを選択
- 移動平均窓とdrop許容値を設定
- 同じ時間・条件で複数回測定
- 平均FPSだけでなくフレーム時間とdrop数も比較
- 最終的なframe pacing評価は実機で実施

目標FPSはiOSへの要求値です。端末温度、省電力モード、画面内容、端末の対応範囲、他の負荷によって、実際のコールバック周期は変化します。Simulatorの結果もMac側の環境に影響されるため、実機ディスプレイの測定値として扱わないでください。

## ビルド

`FPSValidator/FPSValidator.xcodeproj` をXcodeで開き、iOS実機向けにビルドします。
